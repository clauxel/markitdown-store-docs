# Overview

MarkItDown Online provides a browser workbench and hosted workflow around document-to-Markdown conversion. It is intended for researchers, knowledge-base teams, support operations, and developers preparing sources for search, review, RAG, or agent context.

The hosted companion at [markitdown.store](https://markitdown.store/) gives each browser 10 free conversions before paid conversion credits are required.
