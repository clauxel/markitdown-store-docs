# Guides - MarkItDown Online

MarkItDown Online turns PDFs, Office files, tables, images, HTML, archives, and approved URLs into reviewable Markdown with source metadata and operational checks.

## Prepare files for clean conversion

Use original files when possible, split unrelated bundles, label source owners, and confirm permission before OCR or transcription.

## Review a Markdown artifact

Check heading order, tables, links, extracted images, warnings, and whether the output is safe to index.

## Choose hosted vs. local MarkItDown

Use the upstream repo for code ownership and experiments; use the hosted workflow when review, capacity, support, and operations matter.

## Pricing and Support

The first 10 browser conversions are free; paid bundles add hosted conversion capacity, review records, private-worker options, and support.
