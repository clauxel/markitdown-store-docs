# Examples

- Convert an HTML research brief into headings, lists, links, and tables.
- Turn CSV or TSV data into a Markdown table for review.
- Render JSON into readable nested Markdown sections.
- Prepare a PDF, DOCX, XLSX, or PPTX job for the hosted worker path.

Try these examples in the [browser workbench](https://markitdown.store/#convert); sample selection does not spend a conversion until the user runs it.
