# How It Works - DocMarkdown Studio

DocMarkdown Studio turns PDFs, Office files, tables, images, HTML, archives, and approved URLs into reviewable Markdown with source metadata and operational checks.

## Capture the source

Upload a file, paste text, submit an approved URL, or queue a trusted workspace request with the source label attached.

## Choose the narrow converter

Select the local, fetched-response, archive, OCR, transcription, or worker route that matches the source type.

## Review Markdown and warnings

Check headings, tables, links, missing text, extraction confidence, and any provider-specific limitation before reuse.

## Export into the next system

Send the artifact to a RAG index, an agent context bundle, a support article draft, or a downstream review queue.
