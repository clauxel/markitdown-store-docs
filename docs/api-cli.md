# API and CLI

The public site exposes runtime, catalog, usage, analytics, order, and checkout routes under its own domain. Functional conversion APIs should check server-side quota before work begins.

For local conversion, use the upstream Python package or CLI. For hosted use, begin with the [online workbench](https://markitdown.store/#convert) and move to a paid bundle after the 10 free runs.
