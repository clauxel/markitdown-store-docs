# Getting Started

1. Open the [hosted workbench](https://markitdown.store/#convert).
2. Upload a supported source, paste text, or enter an approved URL.
3. Choose table and source-note options.
4. Run the conversion and review the Markdown.
5. Copy or download the result.

The first 10 runs are free. When the counter reaches zero, the next run directs the browser to the [pricing page](https://markitdown.store/pricing/).
