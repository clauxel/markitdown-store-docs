# Concepts

## Free allowance

The allowance is associated with the current browser through a secure first-party cookie. The server decrements the count, so the displayed value and access decision share one source of truth.

## Paid credits

A paid order is associated with the same browser. After the payment provider confirms the order, the bundle's conversion credits become available to that browser.

## Review artifact

Markdown preserves useful text structure but may not preserve the source's visual layout. Review warnings and source notes before downstream use.
